## 📑 作品概要 / Project Overview

### 【背景と目的】
東京都心（上野、新宿、渋谷など）は世界でも有数の強い光害（Bortleクラス8〜9）に囲まれており、星空観測が困難であると誤解されがちです。しかし、適切な遮光や時間帯の選択、あるいは奥多摩や伊豆諸島・小笠原諸島といった島嶼部へアクセスすることで、東京にいながら極上の暗夜を体験できます。
本アプリは、AIの力を借りてこれらの環境を完全シミュレートし、東京の観星ポテンシャルを可視化することを目的として開発しました。

### 【主な機能 / Key Features】
1. **多言語対応 (i18n):** 日本語、简体中文、English、한국어の4カ国語に対応。言語切り替え時に地名や天体データ、Wikipediaリンクまで動的にローカライズされます。
2. **インタラクティブ・星空シミュレーター:**
   観測時間帯（20:00〜翌04:00）のツマミを動かすことで、天球がリアルタイムに回転。さらに、選択した地域の光害レベル（Bortle値）に応じて、都心では見えない暗い星が自動的に減光・消去される科学的なフィルターを搭載。
3. **シーズン別見どころ星座連動:**
   春・夏・秋・冬の季節切り替えにより、当季の代表的な星座（オリオン座、大熊座、天琴座など）がハイライトされ、ワンクリックでシミュレーターとロックオン連動します。
4. **詳細なスポットプロファイル:**
   標高、新宿からの距離、地理座標、そしてプロによる天体観測アドバイス（ワンポイントチップス）を網罗。
